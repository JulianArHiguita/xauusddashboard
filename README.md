# XAUUSD Trading Dashboard

Dashboard profesional de análisis técnico para XAUUSD (Oro) con datos en tiempo real.

## 🚀 Inicio Rápido

### Mismo Dispositivo (Desarrollo Local)

1. **Backend**:
   ```bash
   cd backend
   venv\Scripts\uvicorn main:app --reload
   ```

2. **Frontend**:
   ```bash
   cd frontend
   npm run dev
   ```

3. Abre `http://localhost:5173` en tu navegador

### Múltiples Dispositivos (Red Local)

Ver [CONFIGURACION.md](./CONFIGURACION.md) para instrucciones detalladas.

## 📋 Requisitos

- Python 3.10+
- Node.js 18+
- Cuenta gratuita en [TwelveData](https://twelvedata.com) (API key incluida)

## ⚙️ Características

- ✅ Análisis técnico en tiempo real (RSI, MACD, Bandas de Bollinger, EMA)
- ✅ Señales automáticas de BUY/SELL/NEUTRAL
- ✅ Gestión de riesgo (Stop Loss / Take Profit)
- ✅ Múltiples temporalidades (5m, 15m, 1h)
- ✅ Interfaz en español
- ✅ Modo oscuro profesional

## ⚠️ Descargo

Este dashboard es solo para fines educativos. No constituye asesoría financiera.
